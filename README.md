# Zihang Ma

Personal academic homepage for Zihang Ma, built with Jekyll and adapted from
[academic-homepage](https://github.com/luost26/academic-homepage).

## Local Preview

Install Ruby and Bundler, then run:

```bash
bundle install
bundle exec jekyll serve
```

The site is intended to be deployed through GitHub Pages at:

```text
https://solomoon313.github.io
```
